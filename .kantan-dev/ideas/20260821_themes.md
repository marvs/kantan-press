## Problem / goal

Add Themes as the next feature. In the Admin view there should be a new **Themes**
navigation where users can select or import a theme.

Build the theme engine so that it can be easily imported from a third party.

## Default theme

A default theme ships with the app. It uses the styles found at
<https://techandfi.com/kantan-dev/>, specifically these areas:

- The featured image is full width, and becomes transparent as you scroll down.
- The title.
- The font size and family.
- The sidebar does not matter — that can be done later.
- Should be mobile friendly.

## Decisions

Answered by the user on 2026-08-21.

| Question | Decision |
|---|---|
| How a theme controls page structure | **Liquid templates.** A theme ships sandboxed Liquid templates so a third-party theme can restructure pages without running Ruby on the server. |
| How a third-party theme is installed | **Zip upload in admin.** The user uploads a `.zip` at `/admin/themes`; the app validates the manifest and lists the theme as selectable. |
| Customization after selection | **Theme settings form.** The theme manifest declares a settings schema, the admin renders a form for it, and the values are stored per theme. |
| Branch | **Stay on `main`.** |

## Reference measurements

Extracted from the page named above on 2026-08-21. It runs the WordPress theme
*Independent Publisher* by Raam Dev. Recorded here as the source of truth for
"the styles found in" that URL — not as a decision about how to implement them.

**Cover image** (`#post-cover-image`)

- Full-bleed `background: url(...) no-repeat center; background-size: cover; background-attachment: scroll`.
- `overflow: hidden; padding: 25vh 0 30px; position: relative`.
- A `:before` scrim: `linear-gradient(rgba(0,0,0,0.1) 50%, rgba(0,0,0,0.65))`, plus `box-shadow: 0 -1px 8px rgba(0,0,0,0.2) inset`.
- Responsive padding: `25vh 0 30px` → `35vh 40px 30px` at ≥783px → `48vh 0 30px` at ≥992px.
- Followed by `margin-top: 2.375rem` on the content wrapper.

**Fade on scroll** — the theme fades the *meta block*, not the image:

```js
$meta.css( 'opacity', 1 - ( $window.scrollTop() / $cover.outerHeight() ) );
```

Bound to window `scroll` and `resize`, and triggered once on load.

**Title** (`.cover-meta .single-post-title`)

- `color: white`, `font-size: 2.625rem` → `3rem` at ≥518px, `margin: 0`.
- `text-shadow: 0 1px 3px rgba(0,0,0,0.8)`.
- Sits inside `.cover-meta`: `max-width: 700px; margin: 0 auto; padding: 0 30px; box-sizing: content-box`.

**Cover meta line** (`.cover-meta .entry-meta`)

- `color: rgba(255,255,255,0.73)` (links too), `line-height: 1.65`, `margin: 0.9em 0 0`.
- `text-shadow: 0 1px 1px rgba(0,0,0,0.8)`.
- Contains author, `in <categories>`, date, and a word count.

**Typography**

- Body / UI / headings: `"PT Sans", Helvetica, sans-serif` at `1.1875rem`, `line-height: 1.55`, `color: #383838`.
- Post content (`.entry-content`, `.entry-summary`, `.page-content`): `"PT Serif", Georgia, serif` at `1.063rem`.
- `.entry-title` (non-cover): `#333332`, PT Sans, `2.2em` → `2.5em`, `letter-spacing: -1px`.
- Link hover accent: `#57ad68`. Page background `#fff`.
- Both families are loaded from Google Fonts in weights 400/700 plus italics.

**Breakpoints:** 518px, 783px, 992px, 1330px.
